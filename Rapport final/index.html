Description du mode d'organisation

L'élaboration de notre projet s'est reposé sur plusieurs points pour l'atteinte des résultats énumérés dans le cahier de charge fourni . Dans la section avant celle-ci nous avons listé les membres du groupe rangés par section (Backend, Frontend,Identité Visuel,conception, Rapport,Manuel d'utilisation,...).

Ce découpage nous a beaucoup aidé dans l'organisation, car elle a permis à chaque membre du groupe de s'investir en se concentrant sur la tâche confiée et de bien le faire.

Dans la section suivante , une bref description du fonctionnement de chaque sous_groupe sera présenté

Backend

Le développement du backend avec Django Python et PostgreSQL a permis de créer une plateforme sécurisée et performante pour un site de rencontre. L'utilisation de JavaScript avec Ajax a amélioré l'interactivité et la fluidité des interactions utilisateur. Ce projet démontre l'importance d'une architecture backend solide pour soutenir des applications web dynamiques comme ce site de rencontre, tout en offrant une expérience utilisateur agréable.

Frontend

C'est la partie visible de notre application. Nous avons utilisé les notions de bases: HTML, CSS, Javascript et le framework Bootstrap pour la mise en forme de notre application. L'équipe s'est réparti les tâches liés aux différentes interface pour le gérer dans le temps imparti.

Identité visuelle

L'esprit de créativité des membres du groupe a permis d'obtenir un symbole graphique unique qui nous représente visuellement et nous distingue des autres: Notre logo Une palette de couleurs spécifiques utilisées de manière cohérente à travers tous les supports visuels. Une bonne typographie pour assurer la lisibilité et refléter la personnalité de la marque. Des motifs, textures ou éléments graphiques distinctifs qui peuvent être intégrés dans les designs. pour ajouter de la profondeur visuelle et renforcer l'identité visuelle globale. Un style spécifique pour les photographies utilisées, comme la tonalité des images, le type de contenu visuel, etc.

Conception

La conception planifie l'intégration de fonctionnalités spécifiques selon les besoins du site web, prend en compte des aspects comme l'optimisation des performances pour des temps de chargement rapides, ainsi que la mise en place de mesures de sécurité pour protéger les données des utilisateurs et prévenir les attaques potentielles.La conception aide à organiser et à structurer l'information sur le site de manière logique et accessible. Cela inclut la hiérarchisation du contenu, et la définition des chemins de navigation pour guider efficacement les utilisateurs vers leur destination.

Rapport

Nous avons fais une synthèse sur l'objectif général du projet et ses objectifs précis. Cela a consisté à décrire la méthodologie utilisée, les étapes de conception, les étapes de développement, les étapes liées à l'identité visuel de notre plateforme ainsi que les étapes de déploiement du projet.

Manuel d'utilisation

Nous avons essentiellement eu à présenter nottre application et la manière de l'utiliser. Les fonctionnalités principale ont été présenter dans le manuel d'utilisation, ainsi que le mode de déploiement.
